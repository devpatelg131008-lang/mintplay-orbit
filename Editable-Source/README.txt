TIMBER STRIKE — COMPLETE EDITABLE SOURCE

PLAY AND DEPLOY
The outer Timber-Strike-Vercel.zip contains the ready-to-play index.html,
vercel.json, and a README.md with GitHub/Vercel upload steps.
That index.html embeds every runtime asset. No installation is required.
This Editable-Source.zip is for editing; it is not needed on Vercel.

Tap Play, then tap anywhere on the playfield to throw. Every tap during
active play launches immediately, even with other arrows in flight.
There is no shot cooldown. On a keyboard, Space throws and Escape pauses.
Use the speaker control to mute or enable effects. No music is played.

GAME RULES
One successful hit = one score. Three hearts per run. Seven throws on the
first log, increasing up to twelve. Levels continue without a countdown
or level-complete popup. Colliding with another weapon costs one heart.
Once per run, a free revive restores one heart. It is not an ad view.
Workshop unlocks use best scores 0, 5, 12, 20, 30, 45, 60, 80, 100, 130.

SAVES
Best score and equipped weapons use IndexedDB with a localStorage fallback.
Existing Timber Strike saves on the same website address are retained.
The mute preference is saved separately. Runs themselves are not restored.
If storage is unavailable, progress lasts for the current visit only.
There is no account system, server sync, payment, wallet, or real ad SDK.

BUILD
The readable project lives directly at the root of this source archive:
  src/                   Game code, styles, template, images, and font
  qa/core.test.js         Gameplay regression checks
  build.py               Standard-library Python build script
  vercel.json             Deployment settings to copy beside index.html

With Python installed, run from this folder:

    python build.py

The result is dist/index.html. Copy it over the website's deployed
index.html. All necessary images and the bundled font are already included.
Do not open src/index.template.html as the game; build it first.

Optional engine checks, with Node.js installed:

    node qa/core.test.js

Development-only effect scenarios can be generated with:

    python qa/make-preview.py

Serve the dist folder locally to use qa-effects.html. These test pages
are separate from the production index.html and are not for deployment.

ART AND FONT
ART-DIRECTION.txt records original image-generation prompts.
The background and twelve logs are painted generated assets.
Weapons, faces, leaves, and interface icons are canvas/vector artwork.
Sound effects are generated by the Web Audio API after user interaction.
DejaVu Serif Bold is bundled as a WOFF subset; its license is included
in FONT-LICENSE.txt and embedded in the deployed HTML.
