# Orbit Space

Extract the ZIP and open index.html to play. Tap the arena or press Space to launch. Escape pauses. Starbits buy and equip weapons in the Armory.

For a static deployment, upload index.html to the root of the site. In a fresh GitHub repository, put index.html at the repository root. The optional orbit-pins/index.html redirects old Orbit Pins URLs to the new game.

For a WordPress site, serve index.html as a standalone static file where your hosting setup allows it and link to its address from WordPress. This package is a standalone site.

Armory purchases and scores are saved in the browser. Orbit Space can import the previous Orbit Pins profile on the same origin. The revive is a local preview.
